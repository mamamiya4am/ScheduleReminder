# 开发说明

以下内容原样摘自 [README.md](../README.md) 的第五、六、七节，属于实现与数据细节，供查看源码、修改或维护本程序时参考；只想使用程序的话看 README 即可。

## 一、EXE 图标

`csproj` 已通过：

```xml
<ApplicationIcon>Resources\icon.ico</ApplicationIcon>
```

把 `icon.ico` 嵌入 EXE 文件图标。
窗口/托盘图标由 `IconHelper` 读取 `Resources\icon.ico`；任务栏图标使用高清 `Resources\icon_taskbar.png`，避免 ICO 小帧在任务栏显小。

## 二、数据存储

程序目录下的 `data\`（首次启动自动创建）：

| 文件 | 作用 |
|---|---|
| `schedules.json` | 全部日程（扁平主记录，不预生成重复实例） |
| `settings.json` | 应用设置（悬停延迟 / 界面缩放 / 外观 / 声音 / 开机自启 / AI 设置） |
| `tags.json` | 标签定义（名称 / 背景色 / 文字色 / 音效） |
| `holidays.json` | 内置节假日（示例：元旦 / 春节 / 清明 / 端午 / 中秋 / 国庆，可记事本直接改） |
| `sound\` | 自定义提示音（WAV / MP3） |
| `logs\crash.log` | 异常记录，位于 `data\logs\` 下 |
| `backup\json\` | 自动备份；损坏文件的副本放在 `backup\json\corrupt\` |

设置过自定义窗口背景图后会生成 `background\`；在设置里开启 AI 集成后会生成 `ai\`，内含收件箱 `inbox.json`、回执 `outbox.json` 与只读快照 `snapshot.json`。设置页可生成 `AI操作规则\将此文件给AI读取.md`，该规则已内嵌在程序中，发布包不单独携带。

写入失败（空间只读）时弹置顶模态框「当前空间只读，请移动到其他硬盘空间再试」。

## 三、提示音（音效）

`ISoundService`：`Configure(soundName)` / `Play()` / `Play(soundName)` / `Stop()` / `Preview(soundName)` / `StopPreview()`。

- **音效目录**：`data\sound\`（由发布包直接带出工程 `sound\` 下的内置音效；之后由用户自行增删）。
- **选择方式**：「系统设置 → 提示音 → 日程默认音效」下拉里选择；下拉展开后停留满 **2 秒**会自动试听当前选中项。
- **「-」选项**：永远排在列表最后一位，表示**不播放声音**（提醒照常弹出，只是不响）；即使音效目录为空，「-」也不会消失。
- **文件被删除**：不会崩溃，也不会弹错——静音并写入 `data\logs\crash.log`，不回退系统提示音。
- 播放结束 / 失败会立即释放播放器，避免占用音频文件导致用户删不掉。
- 单次播放最长 3 秒，无论原音频多长都会到时停止。
- `settings.json` 的 `soundFilePath` 只存**文件名**（不是完整路径）；选「-」或未选择时存 `null`。
